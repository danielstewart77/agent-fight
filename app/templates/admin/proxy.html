Each harness and the coordinator connects to the proxy independently, and each is registered in two steps (the model list can only be fetched once the proxy has a key):

  1. Step 1 — enter the base URL and API key, then Save.
  2. Step 2 — the page reloads with the models that key can reach; pick one and Save again.

Base URLs may be the bare root or include /v1. API keys are write-only; leave blank to keep the current value.
